# Third-party components

## libcapt

- Project: https://github.com/darkvision77/libcapt
- Purpose: Canon CAPT v1 protocol implementation and SCoA raster compression.
- License: BSD 2-Clause (see upstream `LICENSE`).
- Source: fetched by CMake FetchContent at build time from the upstream `master` branch.

## captppd reference

- Project: https://github.com/darkvision77/captppd
- Not linked or packaged. Its Linux CUPS/libusb transport is used only as an architectural reference.

The Windows-specific sources in this repository are original prototype code. No Canon binary DLLs are redistributed.
